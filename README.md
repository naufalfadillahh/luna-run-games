# Luna Run & Mini Games

Kumpulan game dan halaman web interaktif, semuanya HTML + JavaScript tanpa build step.

| Halaman | Isi |
|---|---|
| [`index.html`](https://luna-run-games.vercel.app) | **Luna Run**: endless runner kabur dari alien (keyboard atau swipe di HP) |
| [`cibinong.html`](https://luna-run-games.vercel.app/cibinong.html) | **Jagoan Cibinong**: game open world 3D (Three.js) dengan kendaraan, order ojek, minimap, dan kontrol sentuh di HP |
| [`rubik.html`](https://luna-run-games.vercel.app/rubik.html) | **Solver Rubik 3×3**: isi warna kubus, dapatkan langkah penyelesaian (cube.js) |
| [`stanley.html`](https://luna-run-games.vercel.app/stanley.html) | **Botol Minum 3D**: model tumbler 40 oz yang bisa diputar, di-zoom, dan diganti warnanya |
